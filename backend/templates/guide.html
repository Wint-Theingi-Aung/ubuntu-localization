🚀 Getting Started

What You Need

  • Python 3.10+ with uv (fast package manager)
  • Google Gemini API key for AI translation — get one at aistudio.google.com
  • Git configured with GitHub access
  • Launchpad account (optional) for contribution tracking

Installation

git clone https://github.com/Wint-Theingi-Aung/ubuntu-localization.git
cd ubuntu-localization

# Using uv (recommended)
uv sync

# Or using pip
pip install -r requirements.txt

# Set your Gemini API key
echo "GOOGLE_API_KEY=your_key_here" > .env

# Start the server
uv run uvicorn backend.main:app --reload

📥 Obtaining .po Files

From Launchpad (Ubuntu Translations)

  1. Go to translations.launchpad.net/ubuntu
  2. Select your language (e.g., Burmese)
  3. Choose a package to translate (e.g., update-manager)
  4. Click "Download translation" → choose .po format
  5. Save the file and upload it here

From Ubuntu Archives

# Download template .pot file
wget https://translations.launchpad.net/ubuntu/noble/+translations-pots/update-manager/+export

# Or clone a translation branch
git clone https://git.launchpad.net/~ubuntu-translations/ubuntu/noble/update-manager

From Your Own Project

# Generate .pot template from source code
xgettext -o messages.pot src/*.py

# Create a language-specific .po file
msginit -i messages.pot -o burmese.po -l my

📤 Uploading Files

How to Upload

  1. Click Upload in the sidebar or drag-and-drop a .po file
  2. The file is parsed using polib
  3. All entries are extracted — both translated and untranslated
  4. Untranslated strings (empty msgstr) are filtered into a structured queue
  5. You see a summary: total strings, how many are translated, how many need work

What Gets Detected

  • 🔴 Missing: Empty msgstr — needs translation
  • 🟡 Fuzzy: Has a suggested translation — needs human review
  • 🟢 Done: Non-empty msgstr — already translated

File Structure Convention

ubuntu-localization/
├── data/             ← Input .po files
│   ├── burmese_messages.po
│   ├── shan_ui.po
│   └── mon_desktop.po
├── exports/          ← Translated output
│   ├── translated_my_burmese_*.po
│   └── manifest_*.json

🔍 Detecting Missing Strings

After upload, the tool automatically detects and classifies every untranslated entry into priority tiers:

PriorityCategoryExamples
P1High-Visibility UISave, Cancel, OK, Apply, Settings, File, Edit
P2System/OS ContextKernel, Repository, GNOME, Network, Display, Driver
P3Descriptive TextHelp text, descriptions, notifications, dialog messages
P4Format StringsShort technical strings, single words, format specifiers

Recommendation: Start with P1 (highest user impact), then work through P2-P4.

🤖 Translating with AI

How AI Translation Works

  1. Untranslated strings are split into batches of 15-20 for optimal AI performance
  2. Each batch is sent to Google Gemini 2.5 Flash with an Ubuntu-specific system prompt
  3. The AI preserves:
    • Placeholders: %s, %d, {0}, $1
    • Technical terms: Kernel, GNOME, sudo, apt, GRUB, X11, Wayland
    • Brand names: Ubuntu, Canonical, Debian, Firefox
    • Whitespace and newlines character-for-character
  4. Three QA checks run automatically:
    • Placeholder Integrity: Are all format specifiers preserved?
    • Newline Count: Do newline counts match?
    • Non-Empty: Is the translation non-empty?
    • Length Ratio: Is it within 0.3x–4x of original length?

Manual Translation

You can also type translations manually in the side-by-side grid. Changes auto-save when you move to the next field.

Language-Specific Notes

  • Burmese: Unicode only (never Zawgyi), formal register
  • Shan: Preserve tone marks
  • Mon: Verb-final structure
  • Karen: SVO word order

📦 Exporting & Publishing

What Export Does

  1. Writes all translations back to a .po file
  2. Generates a timestamped filename: translated_my_burmese_messages_20260615_1430.po
  3. Saves an export manifest for tracking
  4. Optionally commits to git with a descriptive message

Git Integration

Each export is automatically committed on the ai-enhanced branch:

feat(my): +40 Burmese translations — 70.0% complete

- Translated 40 strings
- Language: Burmese (my)
- Source: burmese_messages.po
- Export: translated_my_burmese_20260615.po

Co-Authored-By: Claude <noreply@anthropic.com>

After Export

  • Push to GitHub: git push origin ai-enhanced
  • Upload to Launchpad: Submit your .po file on translations.launchpad.net
  • Open a PR: Get your translations reviewed before merging
  • Test in Ubuntu: Install the translated package and verify in-context
