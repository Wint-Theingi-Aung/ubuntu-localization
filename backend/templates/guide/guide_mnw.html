📖 ကရိယာဏံ ကၠောန်မာန်မု

ကရိယာဏံ ထံက်ပၚ Ubuntu သွက်ပြန်ဘာသာသွံရ။ ဍေဟ်စကာ Google Gemini AI သွက်ပြန်လိက်ဟွံပြန်ဏီ ပ္ဍဲဝှာင် .po — မဒှ်ဗီုပြၚ်ကောန်ပရဝ်ဂရာမ် Linux တံ။

နကဵုကရိယာဏံ ဗှ်ေကၠောန်မာန်:

  • ပၠောပ် .po ဟွံသေၚ် .pot နူ Ubuntu ဟွံသေၚ် GNOME
  • ရံၚ်မာန် လိက်လဵုပြန်တုဲ လဵုပြန်ဟွံတုဲဏီ
  • စကာ AI Gemini 2.5 Flash ပြန်ဘာသာ
  • ပလေဝ်လိက်ပြန် ပ္ဍဲဗီုရံၚ်လ္ပာ်ၜါ
  • စမ်ရံၚ်ကဵု quality checks (QA)
  • တိတ်ဝှာင် .po သွက်ဒေါင်လုဒ်

သီုဖအိုတ် ကၠောန်ပ္ဍဲမုက်လိက်မွဲ — မုက်လိက်ပြန်ဘာသာ။

  • ဝှာင် .po ဟွံသေၚ် .pot
  • Google Gemini API key (စုတ်ပ္ဍဲ .env)
  • ဟွံဒးပ္တိုန် — ကၠောန်ပ္ဍဲ browser ဂှ်ရ

📤 ပၠောပ်ဝှာင် .po

ဂွံဝှာင် .po နူလဵု

ဗှ်ေဂွံဝှာင် .po နူ:

  • Launchpad Translations — translations.launchpad.net/ubuntu
  • ဝှာင်ဇကု — စကာ xgettext -o messages.pot src/*.py
  • Ubuntu package source — ဝှာင် .po နွံပ္ဍဲဖိုဒါ po/

လၟေၚ်ကမၠောန်

  1. အာပ္ဍဲ မုက်လိက်ပြန်ဘာသာ
  2. ဓဟောတ်ဝှာင် .po ပ္ဍဲဒၞာဲပၠောပ်ဝှာင်
  3. ယဝ်ဟွံတီဘာသာ — ရုဲပ္ဍဲ dropdown
  4. ဍဵု Upload & Parse

ဂကူဝှာင်မထံက်ပၚ

  • .po — GNU gettext
  • .pot — gettext template
  • ဇမၞော်အိုတ်: 50 MB
  • ဒးဒှ် UTF-8

🤖 ဗီုပြန်ဘာသာကၠောန်

ကရိယာဏံစကာ Google Gemini 2.5 Flash ပြန်လိက်အၚ်လိက်ပ္ဍဲဘာသာဗှ်ေ။ Gemini ကၠိုဟ်လဝ် Ubuntu ကဵု Linux၊ ပြန်ဂၠာဲလိက်ခိုဟ်။

လၟေၚ်ကမၠောန်

  1. ပရေင်ပလံၚ် 15: လိက်ဟွံပြန်ဏီ ပံၚ်နကဵု 15
  2. AI ပြန်: ပလံၚ်ကဵု Gemini နကဵုကဵုလဝ်:
    • စွံ %s, %d, {0}
    • လ္ပပြန် Kernel, GNOME, sudo, apt
    • စွံ Ubuntu, Canonical, Debian, Firefox
  3. စမ်ရံၚ် QA:
    • ✅ Placeholder နွံသီုဖအိုတ်ဟာ?
    • ✅ လၟိဟ် newline တုပ်ဟာ?
    • ✅ ပြန်လဝ်ဟာ?
    • ✅ ဇမၞော်လိက်ဗဗွဲဟာ?

ဍဵုကောန်ဒကုတ် Translate

နွံကောန်ဒကုတ် "🤖 Translate Page" — ဍဵုတုဲ ပြန်လိက်သီုဖအိုတ်ပ္ဍဲမုက်လိက်။

📦 တိတ်ဝှာင်

ကာလပြန်တုဲ တိတ်ပ္ဍဲဝှာင် .po မာန်။

ဗှ်ေကလိဂွံ

  • ဝှာင် .po မပံၚ်လိက်ပြန်တၟိကဵုတြေံ
  • ယၟုဝှာင်: translated_<lang>_<source>_<YYYYMMDD>.po

ဗီုတိတ်

ဍဵု "📥 Export .po File" — ဒေါင်လုဒ်ဝှာင်။

ဆက်ကၠောန်မု

  • ပလံၚ် Launchpad: အာ translations.launchpad.net
  • စမ်ပ္ဍဲ Ubuntu: ပြံၚ်ဝှာင် .po ပ္ဍဲ package

💡 ကသပ်ဂၞန် သွက်ကလိဂွံရလဒ်ခိုဟ်အိုတ်

ကသပ်ဂၞန်ယေဘုယျ

  • စကဵုဝှာင်ဍောတ်။ စမ်ကဵုဝှာင်နွံ 20–30 လိက်ကၠာ
  • ပြန်အတိုၚ်လၟေၚ်။ P1 (menu, button) စကၠာ
  • စမ်ရံၚ်လိက်ပြန်။ AI ဟွံကၠောန်ဂွံသီု — ရံၚ် ⚠️
  • လ္ပပြံၚ် placeholder။ %s, %d ဒးစွံ
  • ဂိုၚ်ဒေပ်လဝ်။ ဟွံဒးကၠောန်တုဲသီု — တိတ်ထဝ် တုဲကလေၚ်ကၠုၚ်ဆက်ကၠောန်

ဘာသာမန်

  • မန်နွံကြိယာလက်ကရဴ — လ္ပကူဗီုပြၚ်ဝါကျအၚ်လိက်
  • လိက်မန်တုပ်ကဵုလိက်ဗၟာလ္ၚဵု — ပါ်ခြာအာ
  • ဝါကျဝါတ်ဂှ် စမ်ရံၚ်လိက်ပြန် AI ဗွဲမဂၠိုၚ်
